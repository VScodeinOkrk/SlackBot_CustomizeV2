# Botの文章を編集する方法

## 編集するファイル

このフォルダーの「メッセージ.yaml」をメモ帳やVS Codeで開きます。
右側の文章だけを編集してください。プログラムの変更は不要です。

## 例：参加メッセージを変える

変更前：

```yaml
入退室:
  参加: '{ユーザー} さんが参加しました。ようこそ〜！'
```

変更後：

```yaml
入退室:
  参加: '{ユーザー} さん、いらっしゃい！ゆっくりしていってね。'
```

`{ユーザー}` は、その人へのメンションに自動で置き換わります。
名前を出したくなければ、`参加: 'いらっしゃい！'` のように省略できます。

## どの項目を変えるか

| 項目 | 変わる文章 |
|---|---|
| 入退室 | チャンネルに参加・退出したときの通知 |
| 朝の挨拶 | 起床予定時刻からの分数ごとの返事 |
| おみくじ | 抽選結果と「今日の運勢」の表示 |
| 音楽 | 曲を紹介するとき・取得できないときの返事 |
| ブックマーク | 集約用の親投稿と保存通知 |
| スタンプ | 合計数と内訳の表示 |
| 表示変更 | 名前やアイコン変更の完了・入力エラー |
| 案内 | 「@Hubot ヘルプ」の返信 |

## おみくじの結果を増やす

「結果」の下に `- '文章'` を追加します。どの結果も同じ確率です。
1件以上残してください。結果を増減すると、その日の固定運勢も変わる場合があります。

```yaml
おみくじ:
  結果:
    - '大吉！今日はいいことがありそう！'
    - '吉！お茶でも飲んでのんびり。'
    - '超大吉！好きな曲を聴こう！'
```

上の例は抜粋です。実際のファイルでは「おみくじ表示」などの項目も残してください。

## 複数行で書く

`|-` の次の行から、スペースを2つ増やして書きます。

```yaml
音楽:
  選曲成功: |-
    今日のおすすめだよ！
    {動画URL}
    気に入ったら教えてね〜。
```

## 保存した内容を反映する

1. ファイルをUTF-8で保存します。
2. Hubotフォルダーのコマンド画面で `npm run check:messages` を実行すると書式を確認できます。
3. 起動中のHubotを `Ctrl+C` で停止します。
4. `npm start` で再起動します。

文章は再起動時に読み込みます。以前送ったメッセージは書き換えません。
ブックマークの親投稿は初回作成時のみ、そのときの文章を使います。
Dockerで動かす場合は `docker compose up -d --build` で変更を反映します。

## 編集時の注意

- 左側の項目名と `:`、行頭のスペースは残します。タブは使いません。
- `{ユーザー}`・`{分}`・`{動画URL}` などは自動置換の目印です。使える目印は各項目のコメントに書いてあります。
- 差し込み項目は省略できますが、名前を変更するとエラーになります。
- 文章全体を `'` で囲む場合、中に `'` を書くには `''` と2つ続けます。
- 項目を空にしたり削除したりせず、文章を書いてください。
- このファイルは既存のコミュニティ機能の返信文用です。コマンド名・判定時刻・権限・自動退出の動作は変更しません。
- 追加した独自HubotスクリプトやHubot本体の英語の `help` は、そのスクリプト側の設定です。ここで編集する案内は「ヘルプ」で呼び出せます。
