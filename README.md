# SlackBot_CustomizeV2

Codexを用いて作成したHubotのプログラムです。
RenderとGASを使用して、擬似的に常時稼働させています。

## できること
アイコンと名前の変更（管理者のみ）
画像URLから画像を取得し、アイコンに設定できます。
絵文字をアイコンに設定することもできます。
特定のチャンネル以外に招待された場合、自動的に退出します。
「@メンション 〇〇」と入力することでコマンドを実行できます。

## コマンド
おみくじ機能
今日の運勢
※上記2つはランダム抽選です。

おはよう
既定値からの時間差を計測し、それに応じたメッセージを送信します。

これ聴いて
プレイリストからランダムに選曲し、おすすめの曲をピックアップします。

スタンプ数
付いているスタンプを種類ごとに集計します。
集計対象のスタンプは動的に変更できます。
